# NextBias

<img src="assets/nextbias-logo.png" alt="NextBias logo" width="160">

NextBias is a K-pop discovery website I built to help people find groups, learn about members, and keep up with official information in one place.

**Live site:** [nextbias.com](https://nextbias.com)  
**Code samples:** [Finder demo](demo/) · [Localization](examples/localization.js)

![NextBias](assets/nextbias-showcase.jpg)

## What I worked on

- group finder and searchable directory
- group and idol profile pages
- saved groups and sharing
- mobile layouts
- English and Spanish pages
- source links, corrections, and profile updates

## Code samples

The production codebase is private. This repo contains a few small examples from the project.

- [`demo/`](demo/) — simplified group finder built with HTML, CSS, and JavaScript
- [`examples/localization.js`](examples/localization.js) — English/Spanish path and locale handling

## Tools

HTML, CSS, JavaScript, Node.js, Cloudflare Pages, Google Analytics, and Google Search Console.

NextBias is an independent project and is not affiliated with the artists or agencies listed on the site.
