# NextBias

<img src="assets/nextbias-logo.png" alt="NextBias logo" width="160">

NextBias is a K-pop discovery website I built to help people find groups and learn about their members in one place.

**Live site:** [nextbias.com](https://nextbias.com)

![NextBias](assets/nextbias-showcase.jpg)

## What I worked on

- group finder and searchable directory
- group and idol profile pages
- saved groups and sharing
- mobile layouts
- English and Spanish pages
- source links, corrections, and profile updates
- SEO, sitemaps, and page metadata

## About this repo

The full NextBias codebase is private. This public repo only includes a few small examples from the project.

The `demo` folder has a simplified version of the group finder using a small sample list. The `examples` folder has a short localization example based on the English and Spanish routing used on the site.

### Files

- [`demo/index.html`](demo/index.html)
- [`demo/styles.css`](demo/styles.css)
- [`demo/app.js`](demo/app.js)
- [`examples/localization.js`](examples/localization.js)

## Tools

HTML, CSS, JavaScript, Node.js, Git, GitHub, Cloudflare Pages, Google Analytics, and Google Search Console.

NextBias is an independent project and is not affiliated with the artists or agencies listed on the site.
